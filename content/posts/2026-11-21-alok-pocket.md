ALOK POCKET is the site you're looking at. It started from one question: what if a blog felt like picking up a game controller? It became a small TV on a desk, wired to a controller.

## Goals

- Feel playful on the menus and calm while reading.
- Work with a keyboard, a mouse and a touchscreen equally well.
- Keep writing simple: one Markdown file per post, published with `git push`.

## Details

The screen has four tints: amber, mint, ice and night. Turn the TINT knob, press <kbd>T</kbd>, or use the OPTIONS button. While you read, the screen switches to a pale paper version of the same tint. Sound is off by default: click the speaker to switch it on. Options also has a text size setting and a button that opens a random post.

Read more about the build in [How this blog works](/posts/how-this-blog-works/).
